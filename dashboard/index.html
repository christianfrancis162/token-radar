How the model works

The model is one function, impliedValue, in lib/model.ts. The page recomputes the same number from the same figures in impliedValueOf, so the number on the board and the number in the detail view are the same arithmetic.

  • TVL is the size of the business a token would capitalise. The base is TVL × 0.22.
  • Seven-day growth is the only momentum the snapshot carries. It is clamped to −50%…+150%, because one week can print absurd numbers — the snapshot's own range runs past +4,000% — and a single week should never decide a ranking.
  • Maturity saturates over one year. A protocol that has run 365 days with no token has already proved it can wait; each further year adds ever less.
  • Breadth pays for distribution. Each extra chain adds 4%, up to five, for the users a launch would reach.

Read it honestly

  • “Records no token” means the snapshot's record carries no token — it is not proof the protocol has none.
  • A protocol below the watchlist's $50M floor is no worse a subject than one on it: the watchlist is a floor, never the whole board.
  • Implied value is this entry's own claim, never a prediction of a launch price.
  • Farm steps are a plan, not a promise: airdrops are never guaranteed, and no step here ever asks you to pay to claim.
